# ゲーム仕様

この文書は完成時の製品仕様を定義します。コードに実装済みの範囲はREADMEを参照してください。

## コンセプト

> Discordで通話しながら眺められ、参加したい判断だけに介入できる協力型セミ放置ローグライトRPG

タスクバーのような横長フィールドで、ヒーローたちは自動的に移動し、通常攻撃、スキル使用、基本的な進行判断を行います。プレイヤーは遠征前にビルドと成長方針を整え、遠征中は戦況を眺めながら、必要な場合だけスキル、進行ルート、撤退、高リスクイベントなどへ介入します。

`TBH: Task Bar Hero`の小型表示、自動進行、ビルド構築の考え方を参考にしますが、Discord Heroでは複数人の協力、短時間のセッション、途中参加、通話中の相談を中心に再構成します。

## 設計原則

- プレイヤーが操作しなくても遠征が進行する
- 遠征中に入力待ちで進行を停止しない
- プレイヤー操作は結果に意味がある任意の介入へ限定する
- 遠征前のビルドと作戦設定が自動戦闘へ反映される
- ロビー、ビルド編集、戦闘、結果で画面責務を分離する
- クラスは固定された役割ではなく、ビルドの土台として扱う
- 正解のビルドをプリセットとして押し付けない
- 相性のよい選択肢はおすすめ表示で案内する
- 協力は専用ゲージではなく、編成、状態異常、救助、スキル連携で表現する
- 切断や途中参加によって残ったプレイヤーが過度に不利にならないようにする

## 対応人数

- 対応：1～8人
- 推奨：2～6人
- 初期実装の上限：4人
- 人数不足時は切断プレイヤーや空き役割をAIが補助する

## セッション

- 通常遠征：15～25分
- ボスラッシュ：5～10分
- エンドレス：任意撤退
- 途中参加と再接続を許可する
- 全員退出後はルームを停止し、必要なチェックポイントだけ保持する

## 基本ループ

```text
接続
  ↓
ロビー
  ├─ 必要な場合だけビルドと成長方針を編集
  └─ 準備完了
       ↓
自動遠征
  ├─ 戦闘、スキル、Wave進行
  ├─ 遠征Lv.上昇と自動強化
  └─ ルート／イベントは既定方針で自動決定
       ↓
必要な場合だけプレイヤーが介入
  ↓
ボス戦
  ↓
報酬と戦績
  ↓
ロビーへ戻る／再挑戦
```

クラス、ロードアウト、成長方針は毎回選び直しません。前回保存した設定でロビーへ参加し、変更したい場合だけビルド編集画面を開きます。

遠征中に誰も操作しない場合でも、戦闘、成長、次のWaveへの移動、既定ルートの選択が継続します。

## 操作

### 自動処理

- 移動
- 通常攻撃
- 基本ターゲット選択
- 作戦に基づくアクティブスキル使用
- 通常アイテム回収
- パッシブ効果
- 敵の基本行動
- 経験値獲得
- 遠征Lv.上昇
- 成長方針に基づく遠征強化
- 次のWaveまたは遭遇への移動
- 無投票時の既定ルートとイベント選択
- 切断プレイヤーのAI操作

### プレイヤー入力

遠征進行に必須となる入力は設けません。次の操作は初回設定、遠征前の調整、または任意の介入です。

- 初回のクラス選択
- 装備、スキル、パッシブ、作戦、成長方針の編集
- 準備状態
- アクティブスキルの手動使用または自動使用への割り込み
- 緊急回避
- ルート投票
- アイテム使用
- イベント選択
- 撤退投票

投票やイベント選択に参加しないプレイヤーがいても、制限時間後に既定方針で決定し、遠征を継続します。

## クラスとビルド

### クラスの役割

クラスはキャラクターの根本的な性質を決める「クラスコア」です。クラスだけでパーティー内の役割を固定しません。

クラスコアが決めるもの：

- 基礎ステータスの傾向
- 固有パッシブ
- 固有リソース
- 装備可能な武器や防具の一部
- クラス固有スキルの候補

プレイヤーの実際の戦い方は、武器、装備、アクティブスキル、パッシブ、作戦の組み合わせで決まります。

### ロードアウト

各ヒーローは少なくとも次の要素を持ちます。

- クラスコア
- 武器
- 防具
- 装飾品
- アクティブスキル
- パッシブスキル
- 自動行動の作戦
- 遠征中の成長方針

初回選択時には最低限のスターター装備と既定の作戦、成長方針を自動設定しますが、名前付きプリセットとしては扱わず、すべて自由に変更できます。

### おすすめ表示

プリセットは用意しません。クラスや現在のビルドと相性がよい候補には、おすすめマークを表示します。

おすすめの判定理由には次を使用できます。

- クラス固有特性と相性がよい
- 選択中のスキルや装備と相乗効果がある
- 現在のビルドで不足している機能を補う
- パーティー全体で不足している役割を補う
- 操作や発動条件が分かりやすい

おすすめには理由を表示します。おすすめを選ばない場合も、警告やペナルティは与えません。

### 役割タグ

クラスとは別に、現在のロードアウトから役割タグと能力評価を自動算出します。

役割タグの例：

- 前衛
- 単体火力
- 範囲火力
- 防御
- 回復
- 強化
- 妨害

ロビーではクラス名だけでなく、現在の主要な役割タグを表示します。パーティー全体についても、各能力が十分か、不足しているかを案内しますが、特定クラスの選択を強制しません。

## クラスコア

### ガーディアン

- 高い耐久力
- 攻撃を受けることで蓄積する防御系リソース
- 挑発、バリア、反撃、押し返しを得意とする
- 盾型、妨害型、反撃火力型などを構成できる

### レンジャー

- 高い単体継続火力
- 距離や弱点を利用する固有特性
- 貫通攻撃、クリティカル、弱点付与を得意とする
- 狙撃型、連射型、罠・妨害型などを構成できる

### メイジ

- 炎、氷、雷などの属性を扱う
- 範囲攻撃と状態異常を得意とする
- 属性連携の起点または完結役になれる
- 範囲殲滅型、状態異常型、単体高火力型などを構成できる

### サポーター

- 回復、強化、弱体化を扱う
- 味方の行動やスキル回転を補助する
- 回復だけを強制せず、戦闘支援や妨害にも寄せられる
- 回復型、強化型、弱体化型、戦闘型などを構成できる

## 協力要素

### 属性・状態連携

| 組み合わせ | 効果             |
| ---------- | ---------------- |
| 水濡れ＋雷 | 連鎖感電         |
| 燃焼＋風   | 炎の拡散         |
| 凍結＋強打 | 防御無視ダメージ |
| 挑発＋反撃 | 広範囲カウンター |

特定クラス同士だけで成立させず、装備やスキルによって複数のクラスが連携条件を作れるようにします。

### 救助

HPが0になったプレイヤーはダウン状態になります。味方の自動行動またはプレイヤーの介入によって一定時間内に救助すると復帰します。救助中の味方は攻撃能力が制限されます。

自動作戦では救助の優先度を設定できます。プレイヤーは必要な場合だけ、敵への攻撃継続または特定の味方の救助を指示できます。全員がダウンすると敗北します。

### パーティー構成

パーティー編成の評価は、クラス数ではなく現在のロードアウトから算出します。

例：

```text
前衛       十分
単体火力   十分
範囲火力   少ない
回復       なし
妨害       十分
```

不足があっても出発を禁止しません。相性のよい装備やスキルへおすすめマークを付け、改善方法を提示します。

六葉のクローバー、葉を集める条件、専用の共有ゲージ、共有必殺技は使用しません。

## 遠征Lv.と自動成長

### 遠征Lv.

遠征Lv.は、その遠征中だけ有効な一時レベルです。

- 各遠征は原則として遠征Lv.1から開始する
- 敵の撃破、Wave突破、イベント達成などで経験値を獲得する
- 必要経験値へ到達すると戦闘を止めずに自動でレベルアップする
- 遠征Lv.と遠征強化は遠征終了時にすべてリセットする
- 再挑戦する場合も原則として遠征Lv.1から開始する
- 永続的なヒーロー成長とは別の値として扱う

レベルアップ時に3択画面、確認画面、入力待ちは発生させません。

### 成長方針

プレイヤーはビルド編集画面で、遠征中の自動強化に使用する成長方針を設定します。成長方針はロードアウトと一緒に保存し、遠征ごとに選び直す必要はありません。

初期候補：

| 成長方針       | 優先する強化                                           |
| -------------- | ------------------------------------------------------ |
| ビルド適応     | 現在装備している武器、スキル、パッシブを均等に伸ばす |
| 攻撃重視       | 攻撃力、攻撃速度、クリティカル、状態異常ダメージ     |
| 生存重視       | 最大HP、防御、バリア、自己回復、被ダメージ軽減       |
| スキル重視     | スキル威力、効果時間、クールタイム、固有リソース     |
| 支援重視       | 回復、味方強化、敵弱体化、救助                         |

既定値は「ビルド適応」です。

成長方針は完成済みのビルドを自動装備するプリセットではなく、自動強化候補を評価する際の優先度です。現在のクラスやロードアウトで利用できない強化は選ばれません。該当する候補がない場合は、ビルド適応に近い有効な強化を選びます。

### 自動強化

レベルアップ時は、サーバーが次の順で適用する強化を決定します。

1. 現在のクラス、装備、スキル、パッシブに適用できる候補だけを抽出する
2. 保存された成長方針に従って候補へ重みを付ける
3. 現在のビルドとの相乗効果と、既に取得した遠征強化との組み合わせを評価する
4. 同点の場合は、遠征シードを用いた決定論的な選択で決定する

自動強化の例：

- 通常攻撃の分裂
- クリティカル時の追撃
- 回復時の攻撃効果
- バリア破壊時の爆発
- 状態異常への追加ダメージ
- スキル使用時の味方支援
- 最大HPまたは攻撃力の上昇
- スキルのクールタイム短縮

適用時には戦闘を遮らない小さな通知を表示します。

```text
遠征Lv.6
反撃ダメージ +12%
```

通知を操作しなくても戦闘は継続します。取得済みの遠征強化は成長履歴から確認できます。

### 成長方針の変更とリセット

- 成長方針はロビーまたはビルド編集画面で変更し、次の遠征から適用する
- 通常遠征中は手動の強化選択、振り直し、全リセットを要求しない
- 遠征終了時に遠征Lv.と遠征強化を自動リセットする
- 永続的な装備、スキル、クラスコア、保存済みロードアウトはリセットしない

通常遠征が短時間で完結するため、MVPでは遠征途中の再配分機能を設けません。エンドレスのような長時間モードで必要になった場合は、チェックポイントで「今後のレベルアップへ適用する成長方針」だけを変更できるようにし、取得済み強化の再配分は別途検討します。

## 永続要素

数値差を広げすぎず、主に選択肢を増やします。

- クラスコア
- スキル候補
- 武器と装備効果
- パッシブ候補
- 作戦候補
- 成長方針の候補
- 外見
- エモート
- 称号
- 難易度
- 保存済みロードアウト

遠征Lv.は永続要素に含めません。

## リスクとリターン

- 危険ルート
- 呪われた宝箱
- オーバードライブ
- 強化ボス
- 報酬を確定する撤退
- 先へ進むほど上昇する報酬倍率

パーティー全体への効果は投票で決定します。誰も投票しない場合や同数の場合の処理はルールセットに固定し、入力待ちで遠征を止めません。

## 途中参加と切断

### 途中参加

- 現在の遭遇または安全な合流タイミングで参加する
- パーティーの進行度を基準に遠征Lv.を自動調整する
- 保存済みロードアウトと成長方針を基準に、そのレベル相当の遠征強化を自動生成する
- 参加前の報酬をそのまま獲得させない

### 切断

- キャラクターは保存済み作戦に基づくAI操作へ移行する
- 遠征Lv.上昇と自動強化は切断中も継続する
- 一定時間はプレイヤー枠を維持する
- 再接続時は同じキャラクターへ復帰する
- 長時間戻らない場合は安全なタイミングで離脱扱いにする

## Discord連携

- Discord表示名とアバター
- Activity参加者の反映
- 招待
- Rich Presence
- ボス撃破や記録更新の共有
- 発話中キャラクターの視覚演出

発話量や声量を戦闘力へ直接変換しません。

## 画面構成

上位画面は次の5つに分離します。

1. 接続画面
2. ロビー画面
3. ビルド編集画面
4. 戦闘画面
5. 結果画面

遠征Lv.上昇と自動強化はオーバーレイを開かず、戦闘画面上の小さな通知と成長履歴へ反映します。ルート選択、イベント選択、撤退確認は別画面へ移動せず、必要な場合だけ戦闘画面上のオーバーレイとして表示します。

詳細な画面責務と遷移は[`UI_SPEC.md`](./UI_SPEC.md)を正本とします。

## サーバー権威

サーバーが以下を決定します。

- ダメージと回復
- 敵AI
- クールタイム
- 経験値
- 遠征Lv.
- 成長方針に基づく自動強化
- ドロップ
- ルートとイベントの時間切れ処理
- 勝敗
- 報酬

クライアントが送るのは操作意図と設定変更だけです。
