# ゲーム仕様

この文書は完成時の製品仕様を定義します。コードに実装済みの範囲はREADMEを参照してください。

## コンセプト

> 通話しながら、重要な場面だけ操作する協力型ミニRPG

タスクバーのような横長フィールドで、ヒーローたちが自動的に移動・通常攻撃します。プレイヤーはアクティブスキル、ビルド、進行ルート、撤退、高リスクイベントなどの判断を行います。

## 対応人数

- 対応：1～8人
- 推奨：2～6人
- 初期実装の上限：4人
- 人数不足時は切断プレイヤーや空き役割をAIが補助

## セッション

- 通常遠征：15～25分
- ボスラッシュ：5～10分
- エンドレス：任意撤退
- 途中参加と再接続を許可
- 全員退出後はルームを停止し、必要なチェックポイントだけ保持

## 基本ループ

```text
ロビー
  ↓
クラス選択
  ↓
自動戦闘
  ↓
レベルアップ時の3択強化
  ↓
ルート投票／イベント判断
  ↓
パーティーレリック選択
  ↓
ボス戦
  ↓
報酬と戦績
```

### プレイヤー入力

- クラス選択
- 準備状態
- アクティブスキル
- 緊急回避
- レベルアップ強化
- ルート投票
- アイテム使用
- 共有必殺技への同意
- 撤退投票

## クラス

### ガーディアン

- 挑発
- バリア
- 攻撃の肩代わり
- 敵の押し返し

### レンジャー

- 高い単体継続火力
- 貫通攻撃
- クリティカル
- 弱点付与

### メイジ

- 炎、氷、雷
- 範囲攻撃
- 状態異常
- 属性連携の起点

### サポーター

- 回復
- 攻撃速度強化
- クールタイム短縮
- 高速救助

## 協力要素

### 属性・状態連携

| 組み合わせ | 効果             |
| ---------- | ---------------- |
| 水濡れ＋雷 | 連鎖感電         |
| 燃焼＋風   | 炎の拡散         |
| 凍結＋強打 | 防御無視ダメージ |
| 挑発＋反撃 | 広範囲カウンター |

### 救助

HPが0になったプレイヤーはダウン状態になります。一定時間内に味方が救助すると復帰し、救助中の味方は攻撃能力が制限されます。

### パーティーゲージ

攻撃・支援・救助で共有ゲージが蓄積し、全員に影響する連携技を発動します。

## ビルド

### 遠征中の強化

レベルアップ時に候補から1つ選び、遠征終了時にリセットします。

- 通常攻撃の分裂
- クリティカル時の追撃
- 回復時の攻撃効果
- バリア破壊時の爆発
- 状態異常への追加ダメージ
- スキル使用時の味方支援

### 永続要素

数値差を広げすぎず、主に選択肢を増やします。

- クラス
- スキル候補
- 装備効果
- 外見
- エモート
- 称号
- 難易度

## リスクとリターン

- 危険ルート
- 呪われた宝箱
- オーバードライブ
- 強化ボス
- 報酬を確定する撤退
- 先へ進むほど上昇する報酬倍率

パーティー全体への効果は投票で決定し、同数時の処理はルールセットに固定します。

## Discord連携

- Discord表示名とアバター
- Activity参加者の反映
- 招待
- Rich Presence
