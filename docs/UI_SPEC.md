# 画面構成・画面遷移仕様

この文書はDiscord Heroの完成時における画面構成、画面責務、表示優先度、画面遷移を定義します。

## 目的

現在のゲーム状態で必要な情報だけを表示し、ロビー設定、ビルド編集、自動遠征設定、戦闘表示、結果確認が同じ長い画面へ混在しないようにします。

遠征はプレイヤーが操作しなくても進行します。画面は入力を要求するためではなく、現在の状況を理解し、必要な場合だけ自動判断へ介入できるように設計します。

画面設計では次を優先します。

- 遠征中に入力待ちで進行を止めない
- 自動処理の内容と理由を理解できる
- 必須操作と任意介入を混同させない
- 戦闘フィールドと任意操作を離さない
- 狭いDiscord Activity領域でも主要情報が収まる
- Discordで会話しながら眺められる
- PCとモバイルで情報の優先順位を変えない

## 画面設計原則

### 上位画面を分離する

上位画面は次の5つです。

1. 接続画面
2. ロビー画面
3. ビルド・自動遠征設定画面
4. 戦闘画面
5. 結果画面

ロビー用操作を戦闘画面へ残したり、戦闘中にクラスや方針の設定UIを常設したりしません。

### 遠征中の操作を必須にしない

次の処理は保存済み設定に基づいて自動実行します。

- 戦闘とスキル使用
- 遠征Lv.上昇と自動強化
- Wave間の移動
- ルート選択
- イベント選択
- 続行または帰還判断

自動判断へ介入できる場合も、操作しなければ既定の判断を確定し、そのまま進行します。

### 主操作を1つに絞る

| 画面                 | 主操作                           |
| -------------------- | -------------------------------- |
| 接続                 | 再試行                           |
| ロビー               | 準備完了または遠征開始           |
| ビルド・自動遠征設定 | 変更を保存して戻る               |
| 戦闘                 | 原則なし。必要な場合だけ任意介入 |
| 結果                 | 再挑戦またはロビーへ戻る         |

戦闘画面ではスキルボタンを表示しても、自動使用中であることを明示し、手動操作を要求しているように見せません。

### 自動処理をモーダルにしない

次の処理ではオーバーレイや確認画面を開きません。

- 遠征Lv.上昇
- 自動強化
- 自動ルート投票
- 自動イベント選択
- 自動撤退投票

これらは非モーダルな通知または予告バーとして表示します。詳細や上書きが必要なプレイヤーだけ補助UIを開きます。

### 設定と遠征を分ける

- クラス、装備、スキル、作戦、成長方針、進行方針、撤退基準は遠征前に設定する
- 認証済みプレイヤーの前回設定を初期表示し、変更した項目だけを保存する
- ロビーでは設定内容を要約表示する
- 戦闘中は設定を変更せず、任意の一時上書きだけを許可する
- 通常遠征の途中で成長方針や進行方針そのものを書き換えない

## 画面遷移

```text
起動
  ↓
接続画面
  ├─ 接続失敗 ─→ 再試行
  └─ 接続成功
       ↓
ロビー画面
  ├─ ビルド・自動遠征設定画面
  │    ├─ 保存 ─────→ ロビー画面
  │    └─ キャンセル → ロビー画面
  ├─ 参加者詳細ドロワー
  └─ 遠征開始
       ↓
戦闘画面
  ├─ 自動判断の予告通知
  │    └─ 必要な場合だけ上書きシート
  ├─ パーティー詳細ドロワー
  ├─ 成長履歴ドロワー
  ├─ 遠征ログドロワー
  ├─ 離脱確認ダイアログ
  └─ 勝利／敗北／帰還
       ↓
結果画面
  ├─ 再挑戦 ─────────→ ロビーまたは戦闘
  ├─ 設定変更 ───────→ ビルド・自動遠征設定
  └─ ロビーへ戻る ───→ ロビー
```

遠征Lv.上昇、ルート選択、イベント選択では上位画面を切り替えません。

再接続時はサーバーが保持するゲーム状態へ復帰します。

- ロビー中ならロビー画面
- 遠征中なら戦闘画面
- 勝敗または帰還確定後なら結果画面

## ゲーム状態とUI状態

### ゲーム状態

サーバーが正本を持ちます。

- `lobby`
- `running`
- `victory`
- `defeat`
- `return`

### UI状態

クライアントが表示を管理します。

- 接続中
- ロビー表示
- ビルド・自動遠征設定
- 戦闘表示
- 結果表示
- 自動判断上書きシート
- パーティー詳細ドロワー
- 成長履歴ドロワー
- 遠征ログドロワー
- 離脱確認ダイアログ

遠征Lv.、自動強化、自動票、決定済みルートはゲームデータであり、それ自体をUI状態にしません。

## 共通レイアウト

### ピクセルアートの視覚言語

Discord Heroは一般的なWebダッシュボードではなく、明るい色面を持つドット絵ゲームの画面として表現します。Kenney UI Pack - Pixel Adventureのアセットをアセットカタログ経由で読み込み、用途ごとに次のタイルを使い分けます。

- 青系タイル：接続状態、通常パネル、戦闘フィールド、パーティー情報
- 銅・金系タイル：選択中のビルド、主操作、報酬、遠征の重要情報
- アイボリー枠：接続詳細や解禁情報など、読み物として確認するカード
- 暗色・明色の枠：ログ、補助情報、画面内の領域分け
- 小タイルシート：画面上部の装飾帯と場面転換の目印

背景を暗色一色にせず、青緑・砂色・アイボリーを基調にして、ゲーム状態ごとに視認性を保ちます。アセットURLのハッシュ名はクライアントへ直接記述せず、検証済みカタログから解決します。カタログが利用できない場合も、同じ情報階層を色とピクセル枠のフォールバックで維持します。

### 上部バー

上部バーはコンパクトにし、常に必要なものだけを表示します。

- 現在の場所または遠征名
- 接続状態
- 招待またはメニューへの入口

通常の接続済み状態は目立たせず、再接続中や切断時だけ強調します。

### 通知

- 操作成功は短いトーストで表示する
- 操作拒否は理由と可能な次の行動を表示する
- 通信エラーは戦闘を覆わない
- 遠征Lv.上昇と自動強化は非モーダル通知にする
- 自動判断は確定前の予告バーとして表示する
- 複数通知が重なる場合はまとめる
- 通知を閉じなくても進行する

### 戻る操作

- 設定画面から戻る際、未保存変更があれば確認する
- 戦闘中のブラウザ戻る操作で即座に離脱しない
- 離脱がパーティーへ影響する場合は確認ダイアログを表示する

## 1. 接続画面

### 目的

Discordまたはローカルルームへの接続状態を明確にし、接続失敗時に回復できるようにします。

### 表示要素

- Discord Heroのロゴまたは小型タイトル
- 接続中、認証中、再接続中などの状態
- 参加対象のルーム名
- エラー時の安全な説明
- 再試行ボタン

### 表示しないもの

- クラス選択
- パーティー一覧
- 空の戦闘フィールド
- 空のイベントログ

### 遷移

| 条件     | 遷移先                     |
| -------- | -------------------------- |
| 接続成功 | サーバー状態に対応する画面 |
| 接続失敗 | 接続画面を維持             |
| 再試行   | 接続処理を再実行           |

## 2. ロビー画面

### 目的

参加者、パーティー構成、自動遠征設定を短時間で確認し、必要な場合だけ変更して遠征を開始します。

### 表示要素

- 遠征名、難易度、想定時間
- 参加メンバー一覧
- 各メンバーのクラス、主要役割タグ、準備状態
- 自分のビルド要約
- 成長方針
- 進行方針
- 撤退基準
- パーティー全体の能力評価
- 招待ボタン
- 設定編集ボタン
- 準備完了ボタン
- 遠征開始ボタン

保存済み方針を毎回選ばせず、現在値だけを表示します。

自分の出発準備には、本人専用の永続進行カードを表示します。

- アカウントレベルと経験値バー
- 次のレベルまでの必要経験値
- 所持ゴールド
- 解禁済みコンテンツ数と最近の解禁

このカードはサーバーの`welcome`で受け取った本人の進行だけを表示し、パーティーメンバーの通貨や経験値は表示しません。

```text
成長：ビルド適応
進行：バランス
撤退：標準
```

### パーティーメンバー表示

1人分の表示は次へ限定します。

- Discordアバター
- 表示名
- クラス名
- 主要役割タグ2～3個
- 準備状態
- AI操作中または再接続中の状態

HP、遠征Lv.、クールタイムは表示しません。

### パーティー評価

ロードアウトから算出した能力を、出発制限ではなく案内として表示します。

```text
前衛       十分
単体火力   十分
範囲火力   少ない
回復       なし
妨害       十分
```

不足項目を選択すると、不足を補いやすい装備やスキルを確認できます。特定クラスや特定方針への変更を要求しません。

### 主操作

- 自分が未準備なら「準備完了」
- 自分が準備済みで開始権限があるなら「遠征開始」
- 開始条件を満たさない場合は不足条件をボタン付近に表示する

### 表示しないもの

- 全クラスの選択ボタン一覧
- 全スキルの詳細
- 遠征Lv.の強化候補
- ルート候補
- 戦闘イベントログ
- 使用不能な戦闘ボタン

### ワイヤーフレーム

```text
┌────────────────────────────────────────┐
│ 草原遠征                  接続済み      │
│ NORMAL / 15～25分                      │
├────────────────────────────────────────┤
│ [Avatar] Alice                         │
│ ガーディアン / 前衛・防御・妨害  準備済 │
│ 成長:ビルド適応  進行:バランス   [編集]│
│ [Avatar] Bob                           │
│ メイジ / 範囲・妨害             準備中  │
├────────────────────────────────────────┤
│ 構成評価：前衛 十分 / 回復 少ない       │
├────────────────────────────────────────┤
│ [招待]              [準備完了／遠征開始]│
└────────────────────────────────────────┘
```

## 3. ビルド・自動遠征設定画面

### 目的

クラス、ロードアウト、自動戦闘作戦、自動成長、自動進行を一か所で設定します。

完成済みビルドのプリセット選択は設けません。

### 構成

画面内を次のタブまたは領域に分けます。

1. **ビルド**：クラス、武器、防具、装飾品、スキル、パッシブ
2. **戦闘作戦**：スキル発動、ターゲット、救助、アイテム使用
3. **自動成長**：遠征Lv.の成長方針
4. **自動進行**：進行方針と撤退基準
5. **評価**：役割タグ、相性、おすすめ理由

狭い画面ではタブ表示とし、保存前の変更を維持します。

### 成長方針

初期候補：

- ビルド適応
- 攻撃重視
- 生存重視
- スキル重視
- 支援重視

各方針には優先される強化を表示します。

```text
ビルド適応
装備中の武器、スキル、パッシブを均等に強化します。
```

成長方針を変えても装備やスキルは変更されません。

### 進行方針

初期候補：

- 安全重視
- バランス
- 報酬重視
- 探索重視

各方針には、優先するルートと避けやすいリスクを表示します。

```text
報酬重視
高報酬のエリート戦や危険な宝箱を優先します。
```

### 撤退基準

初期候補：

- 早め
- 標準
- 限界まで

撤退基準には、HP割合などの単一数値だけでなく、パーティー戦力、残存資源、未確定報酬、次の危険度を考慮することを説明します。

### おすすめ表示

おすすめは相性の案内であり、正解の強制ではありません。

```text
★ おすすめ
挑発と反撃を装備しているため、この盾の被攻撃時効果を活用できます。
```

進行方針や撤退基準にはおすすめマークを原則付けません。遊び方の好みとして扱います。

### クラス変更

クラス変更で使用不能になる装備とスキルを確定前に表示します。

```text
メイジへ変更すると、次の項目が外れます。
- 鉄の盾
- シールドバッシュ
```

自動的に別の完成ビルドへ置き換えません。

### 主操作

「変更を保存して戻る」です。

### ワイヤーフレーム

```text
┌────────────────────────────────────────────┐
│ ヒーロー設定                               │
├────────────┬──────────────────┬────────────┤
│ [ビルド]   │ 武器   鉄の盾 ★  │ 前衛  強い │
│ [作戦]     │ 救助   優先       │ 防御  強い │
│ [自動成長] │ ビルド適応        │ 回復  なし │
│ [自動進行] │ バランス / 標準   │ 妨害  普通 │
├────────────┴──────────────────┴────────────┤
│ [キャンセル]                 [保存して戻る] │
└────────────────────────────────────────────┘
```

## 4. 戦闘画面

### 目的

自動で進行する遠征の状況を理解し、必要な場合だけ一時的に介入します。

### レイアウト

1. 戦闘状況バー
2. 横長の戦闘フィールド
3. 状態・任意操作バー
4. 自動判断の予告領域

### 戦闘状況バー

- エリア名
- Waveまたは進行度
- 経過時間または残り時間
- ボスまでの進行
- 自分の遠征Lv.
- 再接続などの重要な通信状態

### 戦闘フィールド

- 味方と敵の位置
- キャラクター識別
- HPとダウン状態
- 重要な状態異常
- ボスの危険行動と予兆
- ダメージと回復の視覚的フィードバック
- 自動救助と自動スキル使用の演出
- 救助中の味方、救助期限、救助クールタイム
- 武器、防具、装飾品の装備状態と発動中の装備相性

細かな数値ログは常時流しません。

### 状態・任意操作バー

- 自分のHPと重要リソース
- 自動使用中のアクティブスキル
- 必要な場合の手動使用または割り込み
- アイテム
- パーティー詳細
- 成長履歴
- 遠征ログ

スキルには自動使用の有効状態とクールタイムを表示します。何もしなくても作戦に基づいて発動します。

### 遠征Lv.上昇

画面遷移やオーバーレイを発生させません。

- 遠征Lv.表示を更新する
- 適用された強化を非モーダル通知にする
- 成長履歴へ記録する
- 短時間に連続した場合はまとめる

```text
遠征Lv.6
反撃ダメージ +12%
```

### 自動判断の予告

ルート、イベント、撤退判断が発生した場合、選択画面を強制表示せず、戦闘画面の端へ予告バーを表示します。

```text
進行方針により「危険な洞窟」を選択
自動票 3 / 4　確定まで 4秒      [変更]
```

予告バーの要件：

- 自動選択された内容
- 判断理由または使用された方針
- 自動票の集計
- 確定までの時間
- 任意の「変更」入口

何もしなければ予告バーが閉じ、選択を確定して進行します。

### 自動判断の上書きシート

「変更」を選んだ場合だけ開きます。

- 自分の現在の自動票
- 選択肢
- 危険度と報酬傾向
- 他プレイヤーの集計票
- 確定までの時間

上書きできるのは自分の票だけです。他プレイヤーの方針や票は変更できません。

上書きシートを開いたまま時間切れになった場合も、現在の票で確定して自動的に閉じます。

### 表示しないもの

- クラス一覧
- ビルド編集
- 作戦や方針の編集
- 準備完了
- 遠征開始
- レベルアップ3択
- 必須のルート投票モーダル
- 空の強化選択パネル
- 常時展開されたイベントログ

### ワイヤーフレーム

```text
┌────────────────────────────────────────────┐
│ 草原 2-3  遠征Lv.6  01:42  Boss 62%       │
├────────────────────────────────────────────┤
│                                            │
│ Hero  Hero  Hero            Enemy  Enemy   │
│                                            │
├────────────────────────────────────────────┤
│ 自動選択: 危険な洞窟 / 確定まで4秒 [変更] │
├────────────────────────────────────────────┤
│ Alice HP 78/120        スキル: 自動使用中  │
│ [Skill] [Item] [Party] [Growth] [Log]     │
└────────────────────────────────────────────┘
```

## 補助ドロワー

### パーティー詳細

- 味方のHP
- 遠征Lv.
- ダウン状態
- 救助対象の選択と救助進行
- 主な状態異常
- AI操作、切断、再接続状態
- 必要な場合だけ詳細ステータス

### 成長履歴

- その遠征で自動適用された強化
- 適用された遠征Lv.
- 成長方針
- 強化の短い選択理由

取得済み強化をここから変更またはリセットしません。

### 遠征ログ

- 参加、切断、再接続
- 遠征Lv.上昇と自動強化
- 自動ルートと自動イベント判断
- プレイヤーによる票の上書き
- ボス行動
- ダウンと救助
- 救助開始、救助完了、救助期限切れ
- 勝敗と帰還

通常攻撃一回ごとのダメージは既定では表示しません。

## 5. 結果画面

### 目的

勝敗または帰還、獲得報酬、主要な戦績を短時間で理解し、次の行動を選びます。

### 表示要素

- 勝利、敗北、帰還
- 到達地点
- 獲得報酬
- 新規アンロック
- パーティーの主要戦績
- 機能したビルド連携
- 遠征中の主要な自動判断
- 再挑戦
- 設定変更
- ロビーへ戻る

結果画面では、現在のプレイヤーに付与される通貨とアカウント経験値を最上位の報酬パネルへ表示します。Queue精算前でも、サーバーが結果に含めた確定値を表示し、後から入力待ちにはしません。結果に含まれる現在プレイヤー向けの新規アンロックIDは、サーバーの結果データだけを根拠に専用パネルへ表示します。

### 戦績の優先順位

- 到達地点
- ボス撃破

## レスポンシブ表示

### 横長・デスクトップ

- 戦闘フィールドを最大領域として確保する
- 状態・任意操作バーをフィールド直下へ固定する
- 自動判断予告をフィールドの下端または右端へ表示する
- ロビーではメンバー一覧と構成評価を横並びにできる
- 設定画面では複数カラムを使用できる

### 狭い画面・モバイル

- 上位画面の責務は変えない
- 戦闘フィールド、予告、状態バーの順を維持する
- 設定画面はタブ表示にする
- 補助情報はボトムシートへ格納する
- 任意操作を画面外へ追い出さない
- 自動判断予告は1～2行へ要約する

## アクセシビリティ

- 色だけで準備、接続、危険度、使用可否を表現しない
- アイコンにはラベルまたは説明を付ける
- キーボードで主要操作へ移動できるようにする
- フォーカス位置を明確にする
- クールタイムを数値でも示す
- 上書きシートを閉じた後に元の操作へフォーカスを戻す
- 点滅や画面揺れを軽減できる設定を用意する
- 自動判断の確定までを色だけでなく数値でも示す

## 状態別の表示優先度

| 状態                 | 最優先                             | 二次情報                 | 隠すもの               |
| -------------------- | ---------------------------------- | ------------------------ | ---------------------- |
| 接続                 | 接続状態と回復手段                 | ルーム名                 | ゲーム操作             |
| ロビー               | 参加者、構成、設定要約、準備、開始 | 遠征情報                 | 戦闘操作、戦闘ログ     |
| ビルド・自動遠征設定 | ロードアウト、作戦、方針、保存     | おすすめ理由、役割評価   | 戦闘フィールド         |
| 戦闘                 | 戦況、遠征Lv.、自動判断の予告      | 任意操作、詳細、履歴     | クラス設定、必須選択UI |
| 結果                 | 勝敗または帰還、報酬、次の行動     | 詳細戦績、自動判断の要約 | 使用不能な戦闘操作     |

## 画面に関する非採用事項

- すべての機能を1ページへ縦に並べる構成
- 戦闘中もロビー設定を表示し続ける構成
- レベルアップ時の3択オーバーレイ
- 入力しないと進行しないルート投票
- 入力しないと進行しないイベント選択
- 全ダメージイベントを常時表示するログ
- 毎回クラスや方針を選ばせる導線
- クラスや役割の完成プリセット選択画面
- 六葉のクローバーまたは専用共有ゲージのUI
