# 画面構成・画面遷移仕様

この文書はDiscord Heroの完成時における画面構成、画面責務、表示優先度、画面遷移を定義します。

## 目的

現在のゲーム状態で必要な情報と操作だけを表示し、ロビー設定、ビルド編集、戦闘操作、結果確認が同じ長い画面へ混在しないようにします。

画面設計では次を優先します。

- プレイヤーが今行うべき操作を迷わない
- 戦闘フィールドと戦闘操作を離さない
- 必要なときだけ選択UIを表示する
- 狭いDiscord Activity領域でも主要操作が画面内に収まる
- 戦闘状況を見ながらDiscordで会話できる
- PCとモバイルで情報の優先順位を変えない

## 画面設計原則

### 状態に応じて画面を分離する

上位画面は次の5つです。

1. 接続画面
2. ロビー画面
3. ビルド編集画面
4. 戦闘画面
5. 結果画面

ロビー用操作を戦闘画面へ残したり、戦闘用操作をロビー画面へ常設したりしません。

### 主操作を1つに絞る

各画面では、その時点で最も重要な操作を主ボタンとして強調します。

| 画面         | 主操作                         |
| ------------ | ------------------------------ |
| 接続         | 再試行                         |
| ロビー       | 準備完了または遠征開始         |
| ビルド編集   | 変更を保存して戻る             |
| 戦闘         | 使用可能なアクティブスキル     |
| 結果         | 再挑戦またはロビーへ戻る       |

### 常設UIと一時UIを分ける

常に必要な情報だけを常設し、次の操作は必要なときだけ表示します。

- レベルアップ強化
- ルート投票
- イベント選択
- 撤退投票
- 離脱確認
- エラー詳細

これらは戦闘画面上のオーバーレイまたはダイアログとして扱います。

### 設定とプレイを分ける

- ビルド編集は独立画面で行う
- ロビーにはビルド結果の要約だけを表示する
- 戦闘中はクラスや装備の編集UIを表示しない
- 結果画面では獲得内容を優先し、詳細編集は別画面へ遷移させる

## 画面遷移

```text
起動
  ↓
接続画面
  ├─ 接続失敗 ─→ 再試行
  └─ 接続成功
       ↓
ロビー画面
  ├─ ビルド編集画面
  │    ├─ 保存 ─────→ ロビー画面
  │    └─ キャンセル → ロビー画面
  ├─ 参加者詳細ドロワー
  └─ 遠征開始
       ↓
戦闘画面
  ├─ レベルアップオーバーレイ
  ├─ ルート選択オーバーレイ
  ├─ イベント選択オーバーレイ
  ├─ パーティー詳細ドロワー
  ├─ ログドロワー
  ├─ 離脱確認ダイアログ
  └─ 勝利／敗北
       ↓
結果画面
  ├─ 再挑戦 ───────→ ロビー画面または戦闘画面
  ├─ ビルド編集 ───→ ビルド編集画面
  └─ ロビーへ戻る ─→ ロビー画面
```

再接続時は、サーバーが保持するゲーム状態へ復帰します。

- ロビー中ならロビー画面
- 遠征中なら戦闘画面
- 勝敗確定後なら結果画面

## ゲーム状態とUI状態

ゲームの進行状態と、クライアント上で開いている補助UIを分けて考えます。

### ゲーム状態

サーバーが正本を持ちます。

- `lobby`
- `running`
- `victory`
- `defeat`

### UI状態

クライアントが表示を管理します。

- 接続中
- ロビー表示
- ビルド編集
- 戦闘表示
- 結果表示
- レベルアップオーバーレイ
- ルート選択オーバーレイ
- イベント選択オーバーレイ
- パーティー詳細ドロワー
- ログドロワー
- 離脱確認ダイアログ

補助UIを開いてもゲーム状態は変化しません。ゲーム状態が変化した場合は、現在の上位画面を対応する画面へ切り替えます。

## 共通レイアウト

### 上部バー

上部バーはコンパクトにし、常に必要なものだけを表示します。

- 現在の場所または遠征名
- 接続状態
- 招待またはメニューへの入口

ゲームタイトルや説明文を大きく常設しません。接続状態は通常時には小さく表示し、再接続中や切断時のみ目立たせます。

### 通知

- 操作成功は短いトーストで表示する
- 操作拒否は理由と次に可能な行動を表示する
- 致命的でない通信エラーは戦闘表示を覆わない
- 再接続中は現在の状態を保持し、操作だけを一時的に無効化する

### 戻る操作

- ビルド編集から戻る場合、未保存変更があれば確認する
- 戦闘中のブラウザ戻る操作で即座に離脱しない
- 離脱がゲーム状態へ影響する場合は確認ダイアログを表示する

## 1. 接続画面

### 目的

Discordまたはローカルルームへの接続状態を明確にし、接続失敗時に回復できるようにします。

### 表示要素

- Discord Heroのロゴまたは小型タイトル
- 接続中、認証中、再接続中などの状態
- 参加対象のルーム名
- エラー時の安全な説明
- 再試行ボタン

### 表示しないもの

- クラス選択
- パーティー一覧
- 空の戦闘フィールド
- 空のイベントログ

### 遷移

| 条件         | 遷移先       |
| ------------ | ------------ |
| 接続成功     | サーバー状態に対応する画面 |
| 接続失敗     | 接続画面を維持 |
| 再試行       | 接続処理を再実行 |

## 2. ロビー画面

### 目的

参加者とパーティー構成を確認し、必要な場合だけビルドを変更して遠征を開始します。

### 表示要素

- 遠征名、難易度、想定時間
- 参加メンバー一覧
- 各メンバーのクラス、主要役割タグ、準備状態
- 自分のビルド要約
- パーティー全体の能力評価
- 招待ボタン
- ビルド編集ボタン
- 準備完了ボタン
- 遠征開始ボタン

### パーティーメンバー表示

1人分の表示は次へ限定します。

- Discordアバター
- 表示名
- クラス名
- 主要な役割タグ2～3個
- 準備状態
- AI操作中または再接続中の状態

HPやクールタイムなど、戦闘中にしか意味を持たない情報は表示しません。

### パーティー評価

ロードアウトから算出した能力を、強制ではなく案内として表示します。

```text
前衛       十分
単体火力   十分
範囲火力   少ない
回復       なし
妨害       十分
```

不足項目を選択すると、不足を補いやすい装備やスキルのおすすめ理由を確認できます。特定クラスへの変更を要求しません。

### 主操作

- 自分が未準備なら「準備完了」
- 自分が準備済みで開始権限があるなら「遠征開始」
- 開始条件を満たさない場合は、不足条件をボタン付近に表示する

### 表示しないもの

- 全クラスの選択ボタン一覧
- 全スキルの詳細
- レベルアップ候補
- 戦闘イベントログ
- 使用不能な戦闘ボタン

### ワイヤーフレーム

```text
┌────────────────────────────────────────┐
│ 草原遠征                  接続済み      │
│ NORMAL / 15～25分                      │
├────────────────────────────────────────┤
│ パーティー                              │
│ [Avatar] Alice                         │
│ ガーディアン / 前衛・防御・妨害  準備済 │
│                               [編集]   │
│ [Avatar] Bob                           │
│ メイジ / 範囲・妨害             準備中  │
├────────────────────────────────────────┤
│ 構成評価：前衛 十分 / 回復 少ない       │
├────────────────────────────────────────┤
│ [招待]              [準備完了／遠征開始]│
└────────────────────────────────────────┘
```

## 3. ビルド編集画面

### 目的

クラスコア、装備、スキル、パッシブ、作戦を直接編集し、現在の役割を確認します。

プリセット選択は設けません。

### 表示要素

- クラスコア
- 武器、防具、装飾品
- アクティブスキル
- パッシブスキル
- 自動行動の作戦
- 現在の役割タグと能力評価
- おすすめマーク
- おすすめ理由
- 保存、キャンセル

### 編集構造

画面を次の3領域に分けます。

1. 現在のクラスとキャラクター
2. ロードアウトの装備枠
3. 役割評価と相性説明

狭い画面では3領域をタブまたは縦並びへ変換しますが、保存前の変更内容は維持します。

### おすすめ表示

おすすめは候補の順位付けではなく、相性の案内です。

表示例：

```text
★ おすすめ
挑発と反撃を装備しているため、攻撃を受けた際に効果を得るこの盾と相性があります。
```

おすすめを選択しなくても警告を出しません。

### クラス変更

クラスを変更した場合、使用不能になる装備とスキルを変更確定前に表示します。

```text
メイジへ変更すると、次の項目が外れます。
- 鉄の盾
- シールドバッシュ
```

自動的に別の完成ビルドへ置き換えません。空いた枠には未設定状態を表示し、保存前に最低限必要な項目だけを案内します。

### 主操作

「変更を保存して戻る」です。

変更がない場合は単に「戻る」と表示しても構いません。

### ワイヤーフレーム

```text
┌────────────────────────────────────────────┐
│ ビルド編集                                 │
├──────────┬────────────────────┬────────────┤
│ クラス    │ ロードアウト        │ ビルド評価  │
│ Guardian │ 武器   鉄の盾 ★      │ 前衛  強い │
│ Ranger   │ 防具   衛兵の鎧       │ 防御  強い │
│ Mage     │ Skill  挑発 ★         │ 回復  なし │
│ Support  │ Passive 防御姿勢 ★    │ 妨害  普通 │
├──────────┴────────────────────┴────────────┤
│ [キャンセル]                 [保存して戻る] │
└────────────────────────────────────────────┘
```

## 4. 戦闘画面

### 目的

戦況を理解し、必要なタイミングでスキルやイベント選択を行います。

### レイアウト

戦闘画面は上から次の3領域で構成します。

1. 戦闘状況バー
2. 横長の戦闘フィールド
3. 自分の操作バー

### 戦闘状況バー

- エリア名
- Waveまたは進行度
- 経過時間または残り時間
- ボスまでの進行
- 再接続などの重要な通信状態

通常の「接続済み」は目立たせません。

### 戦闘フィールド

- 味方と敵の位置
- キャラクター名または識別可能な表示
- HPとダウン状態
- 重要な状態異常
- ボスの危険行動と予兆
- ダメージや回復の視覚的フィードバック

細かな数値ログは戦闘フィールドへ常時流しません。

### 操作バー

- 自分のHPと重要リソース
- アクティブスキル
- アイテム
- パーティー詳細への入口
- ログへの入口

スキルボタンには次を表示します。

- アイコン
- 使用可能か
- 残りクールタイム
- 対象指定が必要か

スキルと戦闘フィールドの間にパーティー設定や長いログを挟みません。

### 表示しないもの

- クラス一覧
- ビルド編集
- 準備完了
- 遠征開始
- 空の強化選択パネル
- 常時展開されたイベントログ

### ワイヤーフレーム

```text
┌────────────────────────────────────────────┐
│ 草原 2-3   Wave 3/5   01:42   Boss 62%    │
├────────────────────────────────────────────┤
│                                            │
│ Hero  Hero  Hero            Enemy  Enemy   │
│                                            │
├────────────────────────────────────────────┤
│ Alice HP 78/120                             │
│ [Skill 1] [Skill 2] [Item] [Party] [Log]  │
└────────────────────────────────────────────┘
```

## 戦闘中オーバーレイ

### 共通規則

- 戦闘フィールドを完全に別ページへ置き換えない
- 背景に現在の戦況を残す
- 選択肢、制限時間、現在の投票状況を明示する
- 時間切れ処理を事前に説明する
- 選択後は自動で閉じる

### レベルアップ

- 3つの強化候補
- 現在のビルドとの相性
- おすすめマークと理由
- 選択制限時間

### ルート選択

- 各ルートの危険度
- 予想される敵またはイベント種別
- 報酬傾向
- 現在の投票数
- 同数時の決定規則

### イベント選択

- 選択による利益
- 明確に分かる範囲の危険
- パーティー全体へ影響するか
- 個人選択か投票か

### 撤退投票

- 現在確定している報酬
- 続行時の報酬倍率
- 敗北時に失うもの
- 現在の投票状況

## 補助ドロワー

### パーティー詳細

戦闘を覆いすぎないサイドドロワーとして表示します。

- 味方のHP
- ダウン状態
- 主な状態異常
- AI操作、切断、再接続状態
- 必要な場合だけ詳細ステータス

### イベントログ

- 重要イベントを優先する
- 参加、切断、レベルアップ、ボス行動、ダウン、救助、勝敗を表示する
- 通常攻撃一回ごとのダメージは既定では表示しない
- 必要に応じてフィルターを提供する

## 5. 結果画面

### 目的

勝敗、獲得報酬、主要な戦績を短時間で理解し、次の行動を選びます。

### 表示要素

- 勝利または敗北
- 到達地点
- 獲得報酬
- 新規アンロック
- パーティーの主要戦績
- 自分のビルドで機能した連携
- 再挑戦
- ビルド編集
- ロビーへ戻る

### 戦績の優先順位

- 到達地点
- ボス撃破
- 獲得報酬
- ダウンと救助
- 成功した属性・状態連携
- 記録更新

総ダメージだけを最上位へ置かず、防御、回復、妨害、救助も評価します。

### ワイヤーフレーム

```text
┌──────────────────────────────────────┐
│ 遠征成功                             │
├──────────────────────────────────────┤
│ 到達：草原 2-5                       │
│ 報酬：ゴールド 120 / 強化素材 3      │
│ 新規：反撃の指輪                     │
├──────────────────────────────────────┤
│ 救助 2回 / 状態連携 5回 / 記録更新   │
├──────────────────────────────────────┤
│ [ビルド編集] [ロビーへ] [もう一度]   │
└──────────────────────────────────────┘
```

## レスポンシブ表示

### 横長・デスクトップ

- 戦闘フィールドを最大領域として確保する
- 操作バーをフィールド直下へ固定する
- ロビーではメンバー一覧と構成評価を横並びにできる
- ビルド編集では複数カラムを使用できる

### 狭い画面・モバイル

- 上位画面の責務は変えない
- 戦闘フィールド、状態、操作バーの順を維持する
- ビルド編集はタブまたは縦並びにする
- 補助情報はボトムシートへ格納する
- スキルボタンはタップ可能領域を十分に確保する
- 主要操作を画面外へ追い出さない

## アクセシビリティ

- 色だけで準備、接続、危険度、使用可否を表現しない
- アイコンにはラベルまたは説明を付ける
- キーボードで主要操作へ移動できるようにする
- フォーカス位置を明確にする
- クールタイムを円形表示だけでなく数値でも示す
- オーバーレイ表示時はフォーカスを内部へ移し、閉じた後に元の操作へ戻す
- 点滅や画面揺れを軽減できる設定を用意する

## 状態別の表示優先度

| 状態       | 最優先                               | 二次情報                  | 隠すもの                 |
| ---------- | ------------------------------------ | ------------------------- | ------------------------ |
| 接続       | 接続状態と回復手段                   | ルーム名                  | ゲーム操作               |
| ロビー     | 参加者、構成、準備、開始             | 遠征情報                  | 戦闘操作、戦闘ログ       |
| ビルド編集 | ロードアウト、役割評価、保存         | おすすめ理由              | 戦闘フィールド           |
| 戦闘       | 戦況、HP、スキル、一時的な判断       | パーティー詳細、ログ      | クラス設定、準備操作     |
| 結果       | 勝敗、報酬、次の行動                 | 詳細戦績                  | 使用不能な戦闘操作       |

## 画面に関する非採用事項

- すべての機能を1ページへ縦に並べる構成
- 戦闘中もロビー設定を表示し続ける構成
- 候補が存在しない強化選択欄の常設
- 全ダメージイベントを常時表示するログ
- 毎回クラスを選ばせる導線
- クラスや役割のプリセット選択画面
- 六葉のクローバーまたは専用共有ゲージのUI
